# 추적 데이터 후보 명세

스킬은 후보를 명세·추천까지만 한다. 트래커로 만들지는 사용자가 판단한다.

## 필드 (Trackers 시트)
| 필드 | 내용 |
|---|---|
| tracker_id | 종목코드-T01 형식 |
| 이름 | 예: {국가A}→{국가B} HS {코드} 수출 금액 |
| 측정 대상 | 무엇을 보여주는가(수요·점유율·가격·재고 등) |
| 연결 요인 | Factors의 factor_id / Claims의 claim_id |
| 연결 세그먼트 | 회사 매출 중 어느 부분과 연결되는가, 그 비중 |
| 소스 | 기관·데이터셋명, URL 또는 API 엔드포인트 |
| 국가 | |
| 주기·공표 지연 | 예: 월간, 익월 하순 공표 |
| 이력 길이 | 확보 가능한 과거 기간 |
| 접근 | 무료 / API 키 필요 / 로그인 필요 / 유료 |
| 자동화 경로 | 스크립트 스케줄(공개 API·파일) / BBG 덤프 / 수동 확인 |
| 기존 트래커 중복 | 사용자가 알려준 기존 트래커와 겹치는지, 기존 매핑이 다른 제품의 프록시인지 |
| 임계 제안 | 예: YoY가 2개월 연속 −20% 이하, 피어 대비 갭 20pp 이상, 월차 2년 스택 기대치 대비 이탈 |
| 리드-래그 결과 | 아래 방법, 수치·기간·표본 수, 근거 시트(Data_*) |
| 추천 | 스케줄 추천 / 실적 시즌 수동 확인 / 불필요 / 교체 + 한 줄 이유 |

## 추천 기준
- 스케줄 추천: (a) 연결 요인이 High 이상이거나 핵심 경영진 주장의 검증 지표, (b) 공표 주기가 월간 이하이고 자동화 가능(공개 API·파일), (c) 리드-래그가 양호하거나 직접 측정치(예: 경쟁사의 해당 제품 월매출).
- 실적 시즌 수동 확인: 분기 데이터, 로그인 필요, 해석에 판단이 필요한 것(transcript 코멘트 등).
- 불필요: 노이즈가 크거나 상관이 약함, 다른 후보와 중복.
- 교체: 기존 트래커 매핑이 회사의 다른 제품(또는 다른 출하 형태)을 보고 있는 것으로 드러난 경우 — 대체 후보를 함께 적는다.
- 여러 종목에 공통으로 걸리는 데이터는 우선순위를 올린다(롤업에서 통합 순위).

## 리드-래그 간이 검증
목적은 "추적할 가치가 있는지" 1차 판단이지 통계적 증명이 아니다.
1. 지표와 회사 해당 세그먼트 매출을 같은 주기(보통 분기)로 맞추고 YoY로 변환.
2. 동행(lag 0)과 지표가 1·2분기 선행하는 경우의 상관계수를 계산.
3. 방향 전환점(YoY 부호 또는 가속/감속 전환)이 일치한 비율을 함께 본다 — 표본이 적을 때 상관보다 유용.
4. 표본 수 n<8이면 "참고"로만 표기. 구조 변화(사업 재편·회계 변경·M&A) 기간은 주석.
5. 결과에 기간·n·상관값·전환점 일치율을 적는다. 데이터를 빠르게 얻지 못하면 "미검증"과 이유.
6. 원자료(월별)·분기 집계·상관계수는 xlsx `Data_{주제}` 시트에 수식(SUMIFS·CORREL)으로 남긴다. 판단 근거를 사용자가 바로 다시 계산할 수 있어야 한다.

## 흔한 후보 유형
- 수출입 통계: 회사 제품 또는 고객 수입품의 HS 코드(자국 수출, 상대국 수입 원산지별, 한국 수출).
  - 제품군별 HS를 분리한다(같은 4단위 안에서도 6단위가 제품군별로 갈린다). HS 후보 2~3개를 각각 검증한다.
  - 세트 HS(예: 원동기+발전기 결합품 8502.xx)와 단체 HS(예: 원동기 단체 8408.xx)·부품 HS를 함께 검증하고, 대당 단가(금액/대수)를 P 지표로 둔다.
  - 목적지 국가 비중 변화(고객 생산거점 이동)를 별도 지표로 둔다.
- 엔화(현지 통화) 환산 수입단가 = HS별 USD/kg × USD/JPY. 회사 GPM과의 리드-래그는 분기 GPM 8개 이상 확보 후에만.
- 월차 공표 종목: 기존점·전사 월차, 2년 스택 기대치(전년 동월 + 당해 YoY가 최근 반기 평균 유지 가정).
- 고객 월매출(대만 등), 고객 capex 가이던스(분기).
- 경쟁사 동종 제품 매출·GM·판매량·ASP(분기·반기), 경쟁사 캐파 증설 일정.
- 업계 지표: 장비 billings, 공작기계 수주, 반도체 매출, 수주·인도 통계, 출하·재고 통계.
- 가격: 현물·계약가, 원재료, 리드타임.
- 정책·이벤트: 규제 시행일, 보조금 공고, 조달 일정.
