# 업계 영상·발표 (선택 단계)

목적: 대상 산업·고객·경쟁사의 최근 3~6개월 컨퍼런스 발표, 경영진 인터뷰, 전시회 영상에서 수요·공급·기술 채택 시점에 관한 발언을 모은다. 공시·실적 자료를 대체하지 않고 보완한다.

## 경로 1 — Agent Reach 자막 (Agent Reach가 설치된 환경이면 우선)
1. 검색: `agent-reach youtube search "<쿼리>" --limit N` (N은 5~10). 쿼리는 현지어 제품어 + 고객·경쟁사명 + 행사명. 결과 JSON에서 제목·채널·게시일·영상 id를 확인하고 최근 3~6개월·공식 채널·발표 영상만 남긴다(최대 10개).
2. 자막: `agent-reach youtube subtitle <id> --lang en` (일본어 영상은 `--lang ja`). 출력은 JSON이고 자막 본문은 `items[0].text`.
3. 긴 자막은 세션에 통째로 붙이지 않는다. JSON을 파일로 저장한 뒤 Python으로 키워드(제품어·고객명·수요·가격·리드타임·채택 시점 등) 주변 구간만 잘라 읽거나, 서브에이전트에 파일 경로를 주고 해당 발언만 요약시킨다.
4. 실패 처리:
   - 429 / RATE_LIMITED → 그 영상은 "partial"로 Errors에 기록하고 넘어간다(재시도 1회 이내).
   - 자막 없음 → "자막 없음"으로 기록하고 넘어간다. 음성 인식(오디오를 외부로 보내는 STT)은 하지 않는다.
5. Agent Reach가 없거나 명령 자체가 실패하면 경로 2로.

## 경로 2 — Gemini Notebook (폴백)
1. 웹 검색으로 같은 조건의 영상 URL을 최대 10개 모은다(제목·채널·게시일 확인).
2. 사용자가 URL 목록을 Gemini Notebook 소스로 추가한다(직접, 또는 Workspace의 Notebook 소스 추가 흐름). 이 요청은 결과 보고에 모아 싣고 그동안 다른 단계를 진행한다(공통 규칙 §2 비차단 요청).
3. Notebook에는 "수요·공급·기술 채택 시점에 관한 발언만, 발언자·영상 URL·타임스탬프와 함께"로 질의하고, 인용이 붙은 답만 가져온다.

## 기록 규칙 (두 경로 공통)
- 발언은 회사 공식 발언 / 전문가 의견 / 커뮤니티 추측으로 구분한다. 근거등급은 공식 발언이라도 발언 자체는 B(반대편 미확인), 추측은 D.
- 0단계 시장 프레임·경영진 주장과 상충하는 발언부터 정리한다.
- 메모로 남길 때는 '사실'이 아니라 '해석·가설'로 분류하고 영상 URL·타임스탬프(또는 자막 구간)를 붙인다. Sources 시트에 게시일·발언일을 분리해 기록한다.
- 하지 않음: Reddit·X 로그인 수집, 자막 없는 영상의 음성 인식.
