# Google Sheets 운영모델 — 원장·검산·시나리오 절차

Google Sheets에서 운영모델(월차·결산단신 기반)을 만들거나 확장할 때 읽는다. Excel 빌드(`build_model.py`)와 별개로, 시트에서 원문 입력→계산→검산을 분리해 정정·재현이 가능하게 하는 절차다. 일본 공시 예가 많지만 구조는 지역 무관.

## 1. 3층 구조: 입력 원장 / 계산 / 검산
- **입력 원장(`In_*` 탭)**: 원문 값만 입력한다. 필수 열 = 태그(`원문`/`계산`/`증권사 추정`/`분석 가정`), 문서ID, 발표일, 쪽, 버전.
- **정정은 덮어쓰지 않는다**: 기존 값을 고치지 말고 새 행(월차) 또는 새 열(결산단신)을 추가하고 버전+1. 이유: 덮어쓰면 동결 전망 재현과 정정 감지가 불가능해진다.
- **계산 탭은 '활성 키'만 읽는다.** 활성 키 규칙: 같은 기간 키에서 당기 > 비교열(前年列·前年同期·前期末), 같은 역할이면 늦은 발표일·높은 버전.
  - ARRAYFORMULA 구현 예:
    `우선순위 = IF(역할="당기",1e6,0) + 발표일`
    `활성 = 우선순위 = VLOOKUP(기간키, SORT({기간키,우선순위},2,FALSE), 2, FALSE)`
- **비교열(前年列)도 입력**해 두고, 같은 기간의 당기 원문과 차이를 검산(정정 감지)에 쓴다.
- **검산 탭**: §2 목록을 PASS/FAIL 열로 둔다. 각 행에 허용오차와 비고(왜 그 허용오차인지)를 적는다.

## 2. 검산 탭 표준 목록
| 검산 | 식·기준 |
|---|---|
| 월차 곱셈 | SSS vs (1+객수)(1+객단가)−1, 허용 0.0015 |
| 점포 롤포워드 | 기초+출점−폐점=기말 (월·분기·지역) |
| 월차↔단신 출·폐점 | 월차 3개월 합 vs 단신 독립분기 출·폐점 |
| 분기말 점포 | 분기말 월차 점포 vs 단신 지역 합계 |
| 기간 정합 | 누적→독립분기→연간 |
| 손익 항등식 | 매출−원가=GP, GP−판관비=OP |
| 구성 대사 | 상품·채널·지역 합계 = 전사 |
| 원장 간 대사 | 새 원장 vs 기존 탭 같은 값 |
| 활성 키 중복 | (기간키) 당 활성 1개 |
| 월 원장 기간 형식 | 월 원장 '월' 열이 'YYYY-MM'이 아니면(분기·연간 값 혼입) FAIL |
| 점유율 항등식 | §5 |
| Forecast_Log 중복·재현 | §9 |
| 동결 전망 스냅샷 재현 | 아래 |

- **切捨 허용오차**: 일본 단신은 百万円未満切捨て라 구성 n개 합계 대사 허용오차는 n−1(6개 지역이면 5), GP−판관비=OP도 ±1이 정상. 허용 0으로 두면 거짓 FAIL이 난다.
- **스냅샷 재현**: 기존 계산 탭(Outlook 등)을 참조하지 말고 새 원장 + Forecast_Log 동결 가정만으로 재계산해 0 차이를 확인한다. 기존 탭을 참조하면 같은 오류를 공유해 검산이 무의미하다.

## 3. 원문 파싱 팁
### 결산단신 PDF (`pdftotext -layout`)
- 손익계산서 쪽 탐지 키워드 `損益計算書`, 영업외 시작 `営業外収益`에서 자른다.
- 연간 결산은 `売上原価` 대신 `商品売上原価` 줄 + 期首/当期仕入/期末 내역으로 나온다.
- `買掛金`은 貸借対照表 다음 쪽(`負債の部`)에 있으므로 앵커를 따로 둔다.
- 쪽은 PDF 물리 쪽과 인쇄 쪽(`- n -`)을 함께 기록한다.

### 월차(月次) PDF
- 표 행 regex: 월 + 지수 6개 + 出店(FC) + 退店(FC) + 月末(FC). 上期/下期/累計 행도 같은 패턴.
- 前年 열은 비교열(역할=비교)로 원장에 저장한다(§1).

## 4. 인계 수치 원문 재확인
- 다른 모델·세션이 작성한 인계문의 수치는 원장에 넣기 전에 원문 PDF의 표 행·열 이름까지 대조한다. 이유: 경쟁사 월차에서 `既存店` 대신 `全店`·`上期累計` 값을 기존점으로 옮겨 적은 사례가 있었다.

## 5. 점유율 분해 (시장 범위별)
- **범위를 섞지 않는다**: 업계 통계(국내 업태 전체), 업계지 주요 N사 합계, 상품 시장(경영진 발언 역산)을 각각 별도 행·태그로 저장.
- **분자를 범위에 맞춘다**: 국내 업태 = 국내 점포 매출(직영+FC 도매), 주요 N사 = 전사 매출(경쟁사 단체/연결 기준은 원문 점유율로 역산해 확인), 상품 시장 = 대리 변수(`분석 가정` 태그).
- **분해**: 시장 기여 = 전년 분자 × 시장 성장률, 점유율 기여 = 증수액 − 시장 기여. 검산 행: 점유율 기여 = 당년 시장 × Δ점유율 (허용 0.01).
- **월·분기 분해**: 연간 시장·경쟁사 값을 월로 균등 분할하지 않는다. 연간 구성 비중(분석 가정) + 동종사 월차 원문 + 미공개 사업자 성장률 r 시나리오(예: 0%, 2%, 대표사 연간 성장률, 5%)로 만든다.
  - 손익분기 r* (대상사 점유율 불변이 되는 미공개 사업자 성장률): `r* = (g_S(1−w_S) − Σ w_i·g_i) / w_R`
    (S=대상사, i=월차 공개 동종사, R=미공개 사업자, w=시장 구성 비중, g=성장률). 월·분기·반기로 산출하고 `r* − 대표사 연간 성장률`(bp)을 함께 표시.
- **월별 자료 확보표**(회사×월: 확보/미확보)를 둔다. 월 원장 기간 형식 검산은 §2.

## 6. 달력 효과 (2년 누적 SSS 모델)
- 2년 누적에는 당년·전년 달력이 모두 들어 있으므로 β는 `Δ(2년 누적) ~ Δ(X_t + X_{t−12})`로 회귀한다(X = 휴일 수 YoY 차). '반사실 대비 차이 ~ 당월 X' 회귀는 오지정이다(실측 사례 R² 0.30 vs 0.69).
- 달력 조정 2년 누적: `(1+SSS−βX_t)(1+전년−βX_{t−12}) − 1`.
- 전망: `SSS_m = (1+Ac) / (1+전년_m − βX_{m−12}) − 1 + βX_m` (Ac = 가정한 달력 조정 2년 누적).
- 대안 β는 버리지 말고 민감도 경로로 남긴다. β 추정 구간은 버전별로 고정한다(자동 확장 금지 — 동결 전망 재현성이 깨진다).

## 7. 경로 분해
- 기준 경로(직전 실적)에서 한 번에 한 변수씩 바꾼 경로를 쌓는다: 기저만 교체 → 2년 누적 평균 회귀 → 객수·객단가 분리 → 달력 → 경쟁사 격차 수렴.
- 각 단계 차이(bp)의 합 = 설명분, `합계 변화 − 설명분 = 잔차(교차항)` 행을 항상 표시한다. 잔차를 숨기면 분해 합이 맞는 것처럼 보인다.
- 셀사이드의 '연초 둔화' 류 주장은 (a) 기저 효과만으로 설명되는지 (b) 2년 누적·격차가 실제로 꺾이는지로 나눠 판정하고, 판별 KPI(다음 월차 값의 경로별 범위)를 함께 낸다.

## 8. 비용 브리지 — 동인 1회 규칙
- 유가·환율 같은 원가 충격은 GPM 한 곳에만 넣는다. 수도광열·운반비에 같은 충격을 다시 넣지 않는다(이중 계상).
- 전달 계수 체인: 공급사 재협상 반영률 P, 재고 회전 지연 `L = 재고일수 / 반기 일수`. 증분 행(×P, ×(1−L))으로 각각 표시.
- 비공개 노출(수입 연동 비중 등)은 공란 → 효과 0으로 두고, 별도 조건부 민감도 격자(노출 × 충격)로 표시.
- 판관비는 전년 동반기 실적에서 bottom-up:
  - 인건비 × (1+점포 증가율) × (1+시급 상승률) × (1+점포당 시간 증가율)
  - 고정비(임차+상각) × (1+점포 증가율) × (1+점포당 증가율 = 직전 반기 실적)
  - 나머지는 매출 비례. 검산: 구성 합 = 판관비 (切捨 허용 n−1).
- 시나리오 표에 '동결재현' 열을 두고, 직전 동결 방식으로 0 차이를 재현한 뒤 다른 시나리오를 비교한다.

## 9. Forecast_Log 운용
- 전망을 동결할 때마다 행을 추가한다(버전·유형·기간·지표·값·근거).
- 신규 공시 없이 모델만 개정한 경우도 새 버전 행으로 기록한다(유형 `사전 전망`, 근거 `모델 개정`). FY OP 전/후 열에 직전 버전·새 버전 값.
- 검산: (버전·유형·기간·지표) 중복, 동결값 재현. 가정을 바꾸면 재현 FAIL이 정상이라고 비고에 적는다.

## 10. Sheets MCP 함정·효율
### 함정
- `update_values`/`update_formulas`의 range에 탭 이름을 빼면 첫 번째 탭에 써진다. 기존 탭 보존 작업에서는 데이터가 덮어써지므로 항상 `'Tab'!A1` 형식으로 쓰고, 쓰기 직후 첫 탭의 해당 범위가 그대로인지 확인한다.
- `YYYY-MM` 문자열은 날짜로 파싱되므로 앞에 `'`를 붙인다.

### 효율 (페이로드·토큰 절감)
- 대량 입력은 값 행렬을 직접 쓰고, 파생값은 행/열당 MAP·ARRAYFORMULA 1개로 줄인다.
- 행 단위 ARRAYFORMULA(예: D:M을 한 셀)로 시나리오 블록을 쓰면 셀별 수식 대비 페이로드 약 1/3.
- append-only 원장을 행 고정 참조할 때는 'ID=행' 검산을 같이 둔다(예: ID 번호+4=행). XLOOKUP 반복보다 페이로드가 훨씬 작다.
- 회사 계획 최신값 자동 선택: `INDEX(SORT(FILTER(계획범위, 항목ID=…, 기간=…), 발표일열, FALSE), 1, 값열)`.
- 서식은 '영역 기본 % + 금액·bp 행만 덮어쓰기'로 repeatCell 수를 줄인다.
